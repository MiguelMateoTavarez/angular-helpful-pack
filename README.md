## 📦 What's Included

This pack automatically installs and configures the following tools:

- **Modern Web Development Essentials** (`trusted-packs.modern-web-essential-pack`) - Base extensions for web development (formatting, theme, docker, auto-rename-tag, error lens, pretty TS errors, etc.).
- **Angular Language Service** (`Angular.ng-template`) - Rich editing experience for Angular templates (autocompletion, diagnostics, navigation).
- **Angular Schematics** (`cyrilletuzi.angular-schematics`) - Run Angular CLI schematics directly from VS Code.
- **PostCSS Language Support** (`csstools.postcss`) - Syntax highlighting and editor support for PostCSS files.

## 🚀 How to Use

1. Once installed, the extensions will download in the background.
2. Press `Ctrl+Shift+P` (or `Cmd+Shift+P` on macOS) to select the **Bearded Theme** and **Flow Icons** if they don't apply automatically.
3. Enjoy a productive, unified Angular development environment!
